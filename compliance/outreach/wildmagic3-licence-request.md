`deberly@geometrictools.com`.

> Request for authoritative Wild Magic 3 License version 1.0c

> Hello Mr Eberly,
>

>
> `Software License Agreement for the Wild Magic (Version 3), Library Version

> non-commercial open-source game project, in source form and compiled into a
> WebAssembly side module?

> The relevant files retain the original Geometric Tools copyright headers.
> Project: https://github.com/jay1110/etlegacy
>
