Compatible servers

Host game

Starts a server inside your browser and drops you straight into the map. A browser cannot accept incoming connections, so this is a local game - to host a match others can join, run a native dedicated server and share it with ?connect=host:port (see docs/web.md).

Player profile

The profile is written to the browser filesystem (IndexedDB) and the game starts with it as the default profile - exactly as if it had been created in the in-game menu. In-game settings are saved into the profile and persist across sessions.
