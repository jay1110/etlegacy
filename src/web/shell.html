Host game

⚠ Keep this browser tab open and in the foreground while you host. A tab in the background (another tab, another window, a minimized browser) is throttled by the browser: the game stops running and everybody who joined loses the connection.
The game runs inside your browser and is announced in the lobby, so other players can join it from "Join games" or with your invite link. Add up to 10 maps to play them one after another in a rotation; with a single map that map simply restarts. Maps that are not part of the stock game are downloaded automatically - by you and by everyone who joins. More bots than free player slots are not possible.

Join games

These games run in other players' browsers. Maps that are not part of the stock game are downloaded before you join.

Player profile

The profile is written to the browser filesystem (IndexedDB) and the game starts with it as the default profile - exactly as if it had been created in the in-game menu. In-game settings are saved into the profile and persist across sessions.
